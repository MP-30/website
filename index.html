AI-Assisted Linux Debugging

AIOps & Local RAG Debug Assistant

A Linux debugging assistant that collects system diagnostics and combines them with retrieved runbooks to generate local-LLM troubleshooting guidance.

Repo Docs
Python 3.12+ FastAPI ChromaDB LM Studio Prometheus

Key Features

  • Collects Linux metrics, Docker stats, logs, processes, and network diagnostics
  • Retrieves relevant troubleshooting runbooks with ChromaDB
  • Sends structured context to a local LLM and parses remediation guidance
Architecture & implementation

System collectors build a single health snapshot and classify recent journal errors. ChromaDB retrieves the closest troubleshooting runbooks, then LM Studio combines those runbooks with the snapshot to generate root-cause analysis and fix commands.

Distributed Document Processing Platform

Asynchronous PDF OCR Pipeline

An asynchronous PDF processing service that queues OCR jobs, tracks their progress, and returns extracted text and failure status through an API.

GitHub Repo Documentation
Python 3.14 FastAPI Celery Redis PostgreSQL 17

Key Features

  • FastAPI accepts PDF uploads and queues work for Celery workers through Redis
  • Exponential-backoff retries for transient OCR failures
  • PostgreSQL stores documents, extracted text, status, and retry errors
Architecture & implementation

FastAPI validates uploads and persists document metadata and content in PostgreSQL, then Redis queues the processing job for a Celery worker. Workers update processing state, retry transient OCR failures, and persist extracted text or the final error.
